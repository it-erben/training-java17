# Java HttpClient – Lösung

Dies ist die Referenzimplementierung zur Übung im Modul `assignments/http-client-api`. Die Klasse
`tech.erben.java17.httpclient.HttpClientWorkshop` enthält die ausgefüllten Methoden für synchrone und asynchrone
Requests, JSON/Form-Bodies, Datei-Downloads/-Uploads, Redirects, Auth und Streaming.

Tests ausführen:
```bash
mvn -pl solutions/http-client-api-solution test -DskipTests=false
```
