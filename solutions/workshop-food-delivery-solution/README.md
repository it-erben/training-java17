# Food Delivery Board – Lösung

Die Lösung erweitert das Trainingsmodul um zusätzliche Switch-Expressions, Pattern-Matching-Fälle und eine Statusübersicht.

## Highlights

- Ergänzter `PaymentIssue`-Event wird per Pattern Matching behandelt
- Switch Expression für Lieferzonen (`zoneByDistance`) sowie Status-Zusammenfassung
- Sortierte Lieferliste und Badge-Logik zur schnellen Übersicht

## Ausprobieren

```bash
mvn -pl solutions/food-delivery-modern-java-solution spring-boot:run
```

Port: 9183

Vergleiche mit dem Basis-Modul, um Mehrwert und zusätzliche Modern-Java-Features zu sehen.
