# Text Blocks Barbershop – Lösung

Die Lösung ergänzt das Trainingsmodul um zusätzliche Vorlagenvarianten (HTML-Mail, Markdown, SQL, Promotion).

## Highlights
- Erweiterte Services mit mehreren Text-Block-Beispielen (`sql`, `markdown`, `promotion`, `escapes`)
- Controller senkt Dopplung durch `TemplateVariant`-Record
- UI zeigt die neuen Varianten gesammelt an

## Ausprobieren
```bash
mvn -pl solutions/text-blocks-barbershop-solution spring-boot:run
```
Port: 9182
