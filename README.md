# Java 17 & 21 Kursmodule

Übungsaufgaben zu den Neuerungen bis Java 17 und 21

## Struktur
- `assignments`: Aufgabenstellungen
- `solutions`: Beispiel-Lösungen
- `trainer`: Begleitende Trainer-Module, z.B.
  - `trainer/jpa-records-examples` für JPA-Records als Embeddables und DTO-Projektionen
  - `trainer/jigsaw-greetings-module` + `trainer/jigsaw-greetings-app` als kleines Java-9-Jigsaw-Duo (Modul + Consumer)
  - `trainer/foreign-memory-api` für die Foreign Memory API in Java 21
  - `trainer/vector-api` für die Vector API (Java 21, incubating)
